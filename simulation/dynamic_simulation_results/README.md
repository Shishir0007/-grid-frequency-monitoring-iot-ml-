# Dynamic Simulation Results

Frequency response of the Banepa bus under four disturbance cases, simulated in
DIgSILENT PowerFactory:

- `case1_load_increment/` — active power increased 50% at all load buses
- `case2_load_decrement/` — active power decreased 50% at all load buses
- `case3_load_outage/` — second-largest load disconnected
- `case4_generator_outage/` — Sunkoshi Hydropower (second-largest generator) disconnected

Each case shows the Banepa bus response.
